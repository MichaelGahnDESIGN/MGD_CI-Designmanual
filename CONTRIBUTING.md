# Mitwirken

## Grundsätze

- Eine Änderung behandelt möglichst nur einen fachlichen Bereich.
- Inhalte, Komponenten und Exportlogik werden getrennt gehalten.
- Neue Manual-Abschnitte brauchen ein Datenmodell, eine Editor-Ansicht und eine Vorschau.
- Vor einem Merge werden Linting, Tests und ein Export-Smoke-Test ausgeführt.

## Branches

- `main`: stabiler, vorzeigbarer Stand
- `feature/<thema>`: neue Funktionen
- `fix/<thema>`: Fehlerkorrekturen
- `docs/<thema>`: Dokumentation und Wiki
