# Inhaltsmodell für professionelle Designmanuals

Ein überzeugendes Manual ist kein starres PDF, sondern ein System aus Prinzipien, Regeln, Belegen und konkreten Anwendungen. Der Editor muss deshalb fünf Ebenen verbinden: Markenkern, visuelle Identität, digitale Anwendung, Kommunikation und Governance.

## Kapitelbibliothek

| Ebene | Module |
| --- | --- |
| Orientierung | Cover, Version, Inhaltsverzeichnis, Kontakt und Gültigkeit |
| Markenkern | Zweck, Positionierung, Werte, Zielgruppen, Persönlichkeit und Tonalität |
| Signet | Logo-Varianten, Schutzzone, Mindestgrößen, Hintergründe und Fehlanwendungen |
| Visuelles System | Farben, Typografie, Raster, Layout, Formen, Icons, Illustration und Bildsprache |
| Digital | Tokens, Komponenten, Zustände, Responsive Regeln, Barrierefreiheit und Motion |
| Kommunikation | Sprachstil, Schreibregeln, Botschaften, Claims und Textbeispiele |
| Social Media | Plattformrollen, Formate, Content-Säulen, Templates, Caption-Stil, Hashtags und Freigabeprozess |
| Anwendung | Mockups, Vorlagen, Do's & Don'ts und Praxisbeispiele |
| Governance | Eigentümer:in, Versionshistorie, Änderungsprozess, Downloads und Ansprechpartner |

## Regeln statt bloßer Beispiele

Jedes Modul unterstützt mindestens: Erklärung, verbindliche Regel, positives Beispiel, Negativbeispiel und verwendbare Werte. Bei Farbe sind das zum Beispiel Hex/RGB/CMYK sowie Kontraststatus; bei Logo Schutzzone und Mindestgröße; bei Social Media Bildformat, Textlänge und Freigaberegel.

## Zugänglichkeit als Standard

Der Editor prüft Kontrast und kennzeichnet offene Punkte. Zugänglichkeit betrifft zusätzlich sinnvolle Alternativtexte, Struktur, verständliche Sprache, ausreichende Touch-Ziele und keine Information, die nur über Farbe vermittelt wird. Die endgültige Konformitätsbewertung bleibt ein fachlicher Qualitäts- und Testschritt.
